## 2024-08-27 - [Debouncing Synchronous I/O in UI Event Listeners]
**Learning:** In the Vanilla JS frontend, high-frequency event listeners (like 'input' on textareas) that trigger synchronous I/O operations (e.g., `JSON.stringify` + `localStorage.setItem` as seen in `saveScratchpadState`) can severely block the main thread and cause UI thrashing. Directly writing to `localStorage` on every keystroke is an anti-pattern.
**Action:** Always wrap these expensive I/O operations with a `debounce` utility (e.g., 300ms delay) so the DOM updates fluidly while state is saved efficiently. Crucially, accompany this with a `window` `beforeunload` event listener to synchronously flush pending saves to prevent data loss if the user closes the application before the debounce timeout fires.
