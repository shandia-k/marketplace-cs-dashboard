## 2024-05-31 - [Path Traversal in Electron Session fromPartition]
**Vulnerability:** The application took unvalidated inputs via IPC handlers (e.g., \`clear-store-cache\`, \`deep-clean-store\`, \`admin-clear-store-session\`) and passed them directly to \`session.fromPartition(partition)\`. An attacker could send a partition string like \`persist:../../some/sensitive/dir\` to potentially access, clear, or manipulate files outside the intended cache directory.
**Learning:** In Electron, \`session.fromPartition\` uses the partition string as a directory name if it starts with \`persist:\`. Without validation, this behaves similarly to a path traversal vulnerability during cache clearing operations.
**Prevention:** Always validate and sanitize partition strings passed from the renderer before using them in main process APIs like \`session.fromPartition()\`. Ensure the partition string only contains allowed characters (e.g., alphanumeric, hyphens, underscores) and does not contain directory traversal characters like \`/\`, \`\\\`, or \`..\`.
